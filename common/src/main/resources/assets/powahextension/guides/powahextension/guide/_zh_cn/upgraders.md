# 机器升级器

每个 Powah 等级对应一个升级器，可把**恰好低一级**的机器升到对应等级。

| 升级器 | 升级方向 |
| --- | --- |
| <ItemLink id="powahextension:upgrader_basic" /> | 初级 → 基础 |
| <ItemLink id="powahextension:upgrader_hardened" /> | 基础 → 硬化 |
| <ItemLink id="powahextension:upgrader_blazing" /> | 硬化 → 烈焰 |
| <ItemLink id="powahextension:upgrader_niotic" /> | 烈焰 → 钻石 |
| <ItemLink id="powahextension:upgrader_spirited" /> | 钻石 → 富生 |
| <ItemLink id="powahextension:upgrader_nitro" /> | 富生 → 下界 |

## 合成

六个升级器共用同一个配方形状：**对应等级电容 ×4 + 对应等级材料 ×4 + 介电外壳 ×1**。

```
C M C
M D M     C = 对应等级电容
C M C     M = 对应等级材料，D = 介电外壳
```

| 等级 | 材料（M） |
| --- | --- |
| 基础 | 介电浆糊 |
| 硬化 | 充能钢 |
| 烈焰 | 烈焰晶体 |
| 钻石 | 钻石晶体 |
| 富生 | 富生晶体 |
| 下界 | 下界晶体 |
