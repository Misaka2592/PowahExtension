# PowahExtension

为 Powah! Rearchitected 添加 Mekanism 风格的**机器升级器**。

升级机器再也不用拆了重放。合成一个 <ItemLink id="powahextension:upgrader_basic" /> 升级器，
**潜行 + 右键**机器即可原地升级 —— **能量、物品、流体、红石设置全部保留**。
