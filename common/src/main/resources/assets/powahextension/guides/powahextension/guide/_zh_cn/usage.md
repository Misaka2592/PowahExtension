# 使用升级器

手持升级器，**潜行 + 右键**一台 Powah 机器。

* 机器等级必须**恰好比升级器低一级**。
* 机器**原地**替换 —— 不掉落任何物品，不需要重新接线。
* 内部一切数据保留：**能量**、**物品栏**、**流体罐**、**红石模式**和朝向。
* 每台机器消耗一个升级器（创造模式不消耗，可在配置中修改）。

普通右键（不潜行）仍然正常打开机器 GUI。

## 支持的机器

默认支持所有单方块机器，**包括能量电缆**：
熔炉发电机、岩浆发电机、热力发电机、太阳能板、能量单元、充能棒、
玩家传输器、能量漏斗、能量放电器。

默认排除（可在配置中开启）：

* **反应堆** —— 升级单个部件会破坏已成型的多方块结构。
* **末影单元 / 末影道门** —— 绑定频道网络。
