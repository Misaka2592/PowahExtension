# 批量升级

手持升级器，按 **潜行 + 疾跑（默认左 Ctrl）+ 右键**，一键升级整片**连通**的机器。

## 预览

按住潜行 + 疾跑并看向机器时，所有将被升级的机器都会显示**升级器等级颜色**的
边框 —— 所见即所得。

## 工作原理

* 从点击的方块开始，通过**该升级器可升级的连通机器**洪泛扩散，全部升级。
* 洪泛**不会**穿过其他方块（或等级不符的机器），混合等级阵列会在边界处截断。
* 每台机器消耗**一个**升级器；生存模式下受手上物品数量限制。
* 批量有硬上限（默认 **64** 台，见配置 `batchUpgradeLimit`）——
  即使是巨大的电缆网络也能瞬间完成，不会卡顿。

升级太阳能农场、电缆干线或一整面能量单元墙时，再也不用逐台操作了。
