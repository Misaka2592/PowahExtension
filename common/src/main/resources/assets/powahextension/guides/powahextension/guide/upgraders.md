# Machine Upgraders

One upgrader per Powah tier. Each upgrader raises a machine **exactly one tier below**
it to its own tier.

| Upgrader | Upgrades |
| --- | --- |
| <ItemLink id="powahextension:upgrader_basic" /> | Starter → Basic |
| <ItemLink id="powahextension:upgrader_hardened" /> | Basic → Hardened |
| <ItemLink id="powahextension:upgrader_blazing" /> | Hardened → Blazing |
| <ItemLink id="powahextension:upgrader_niotic" /> | Blazing → Niotic |
| <ItemLink id="powahextension:upgrader_spirited" /> | Niotic → Spirited |
| <ItemLink id="powahextension:upgrader_nitro" /> | Spirited → Nitro |

## Crafting

All six share the same pattern: **4 tier capacitors + 4 tier materials +
1 dielectric casing**.

```
C M C
M D M     C = capacitor of the tier
C M C     M = tier material, D = dielectric casing
```

| Tier | Material (M) |
| --- | --- |
| Basic | Dielectric Paste |
| Hardened | Energized Steel |
| Blazing | Blazing Crystal |
| Niotic | Niotic Crystal |
| Spirited | Spirited Crystal |
| Nitro | Nitro Crystal |
